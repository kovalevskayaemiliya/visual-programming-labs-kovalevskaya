## Описание лабораторной работы №1

В рамках лабораторной работы №1 настроен Git-репозиторий, освоены базовые команды Git,
созданы диаграммы процесса оформления страхового полиса в четырёх нотациях:

- **BPMN** — бизнес-процесс с двумя XOR-шлюзами, ветвлением и циклом возврата.
- **UML Activity** — детализация шага «Проверка андеррайтером».
- **Sequence Diagram** — обмен сообщениями между 5 участниками с блоком `alt`.
- **Flowchart** — алгоритм расчёта стоимости полиса.

Продемонстрирована разница между текстовыми и бинарными форматами при версионировании
(`.bpmn` vs `.png`).
