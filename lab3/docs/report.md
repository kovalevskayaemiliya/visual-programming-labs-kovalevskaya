# Отчёт по лабораторной работе №3. Bubble

## Тема: Список путешествий

### Что я сделала

Я сделала приложение «Список путешествий» в Bubble. В нём можно:
- Зарегистрироваться и войти.
- Добавлять места, куда хочу поехать.
- Редактировать и удалять их.
- Ставить статус: запланировано, в процессе, завершено, отменено.
- Смотреть статистику в профиле.

### Промпт, который я вводила

Создай приложение на тему «Список путешествий». Пусть этот сайт будет требующий регистрацию. Страницу обязательно создай по структуре header + body + footer. Обязательно укажи в заготовке следующую строку: «ТВП: Ковалевская». Добавь несколько интерактивных элементов (реализующих CRUD).

- Как генерировать приложение через AI-агента.
- Как работать с Build Guides (посмотрела руководство «Add, edit, and delete places»).
- Как делать Global Variables (сделала primary-color).
- Как делать стили (сделала travel-primary-button).
- Как добавлять готовые компоненты (Testimonial).
- Как создавать базу данных (Data Type Place).
- Как делать CRUD через workflows (Create, Read, Update, Delete).
- Как работать с Git и GitHub.

### Выводы

Мне понравилось работать в Bubble. Самое классное — что не надо писать код, всё делается мышкой. AI-агент здорово помогает: написал промпт — и приложение готово.

Самое сложное было — настроить workflows для редактирования и удаления. Я долго не понимала, как передать данные из списка в форму редактирования. Оказалось, надо использовать Popup и Display data.

Ещё было сложно с Git — когда я первый раз запушила, не все файлы попали на GitHub. Пришлось разбираться с командами add, commit, push.

Теперь я понимаю, как работает no-code разработка, и могу сделать простое приложение сама.
