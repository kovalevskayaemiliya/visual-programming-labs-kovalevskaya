## 1. Краткое описание приложения и реализованные ачивки

В ходе лабораторной работы было создано мобильное приложение на платформе Kodular (low-code). Проект состоит из двух экранов.

**Базовое задание (Приложение «Приветствие»):**
На первом экране (Screen1) реализован интерфейс для ввода имени и получения приветствия. При нажатии на кнопку приложение проверяет, не пустое ли поле ввода. Если пусто — выводится ошибка «Введите имя!». Если текст введен — выводится персональное приветствие (например, «Привет, Эмилия!»). Также на экране размещена обязательная метка с фамилией студента на английском языке (Kovalevskaya).

**Реализованная ачивка:**
*   **Ачивка 10: Простой калькулятор.** На втором экране (Screen2) реализован калькулятор для сложения и вычитания двух чисел. Добавлена навигация между экранами.

## 4. Освоенные компоненты и блоки

**Компоненты (UI):**
*   `Label` — для вывода заголовков, текста приветствия и результатов вычислений.
*   `TextBox` — для ввода имени и чисел. В настройках калькулятора свойство `InputType` было изменено на `Number` для предотвращения ошибок.
*   `Button` — для запуска событий (приветствие, переход на экран, математические операции, возврат).
*   `Screen` — для организации многоэкранной навигации.

**Блоки (логика):**
*   `when ... .Click do` (события нажатия).
*   `if / then` и `if not / then` (условные операторы из раздела Control/Logic).
*   `set ... .Text to` (изменение свойств компонентов).
*   `join` (соединение строк из раздела Text).
*   `open another screen` и `close screen` (навигация).
*   Математические блоки `+` и `-` (из раздела Math).

## 7. Выводы
В ходе лабораторной работы я освоила платформу Kodular для визуальной разработки Android-приложений. Я научилась создавать пользовательский интерфейс из готовых компонентов (Label, TextBox, Button), настраивать их свойства (например, тип вводимых данных), а также писать логику с помощью визуальных блоков. 

Особенно полезным было разобраться с условными конструкциями (if/then) для валидации ввода и с математическими блоками для создания калькулятора. Также я отработала навыки создания многоэкранных приложений (навигация через `open another screen` и `close screen`). Среда Kodular показалась мне очень интуитивной и удобной для быстрого прототипирования простых мобильных приложений без написания кода.
