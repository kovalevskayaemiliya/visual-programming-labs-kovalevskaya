# Sequence Diagram: Оформление страхового полиса

```mermaid
sequenceDiagram
    participant C as Клиент
    participant A as Агент
    participant S as Система скоринга
    participant U as Андеррайтер
    participant P as Платёжная система

    C->>A: Подать заявку на полис
    A->>S: Передать данные для оценки
    S-->>A: Базовый тариф и уровень риска
    alt Сумма > 1 000 000 руб.
        A->>U: Запрос ручной проверки
        U-->>A: Решение
    else Сумма <= 1 000 000 руб.
        A->>A: Автоматическое одобрение
    end
    A->>C: Предварительный договор
    C->>P: Оплата полиса
    P-->>A: Подтверждение транзакции
    A->>C: Активированный полис
```
